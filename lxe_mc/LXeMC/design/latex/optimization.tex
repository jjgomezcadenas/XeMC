\section{Measurement caveats}

Early benchmarks ($\leq$5k events from CLI) include Julia JIT compilation
overhead, which dominates for small $N$. Numbers below 50k events from
a cold session are unreliable. Warm-loop measurements (200k+ events,
post-warmup) are marked with~*.

\textbf{Key physics parameters (current):}
\begin{itemize}
  \item Te\_cut = 400\,keV (CSDA range 0.74\,mm)
  \item k\_min = 50\,keV (photon mfp 0.27\,mm)
  \item Egamma\_cut = 10\,keV (mfp 0.027\,mm)
  \item Step = 1\,mm fixed
  \item All sub-cut: deposit locally. SS/MS classification at 3\,mm
        z-resolution, 10\,keV cluster threshold.
\end{itemize}

\section{Remaining opportunities}

\begin{itemize}
  \item \textbf{StaticArrays SVector\{3,Float64\}}: would eliminate
        $\sim$9\,KB/event of heap allocations from
        \texttt{Vector\{Float64\}} temporaries in position/direction
        vectors. Estimated 20--30\% further gain. Requires changing Track,
        Deposit, and all transport functions.
\end{itemize}

\section{Performance summary}

At 293k events/sec (warm), $10^8$ events takes $\sim$5.7 minutes.
Photon-only mode runs at $\sim$400k+ events/sec.

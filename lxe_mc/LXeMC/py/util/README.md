# Utility scripts

- `show_detector_tree.py` — Print tracking detector geometry as indented tree
- `compute_geometry_fix.py` — Compute detector dimensions with uniform ICV wall thickness
- `compute_icv_inner_surface.py` — Compare ICV inner surfaces vs tracking detector boundaries
- `compute_icv_masses.py` — Compute ICV head masses preserving mass with fixed R_inner
- `validate_activities_vs_paper.py` — Validate source activities against published values
- `validate_geometry_vs_paper.py` — Validate source geometry against published values
